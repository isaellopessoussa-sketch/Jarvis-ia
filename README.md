# 🕶️ JARVIS - Assistente Virtual Inteligente

> "Online and ready, Sir."

Este é o repositório do **JARVIS**, um assistente virtual inspirado na obra do Homem de Ferro, construído em Python e integrado à Inteligência Artificial do Gemini (Google). O objetivo do projeto é criar um assistente por voz com sotaque britânico, capaz de conversar e executar comandos.

---

## 🚀 Funcionalidades Planejadas

- [x] Criação da estrutura base no GitHub.
- [ ] Conexão com o cérebro da IA (API do Gemini).
- [ ] Sistema de voz (Speech-to-Text e Text-to-Speech).
- [ ] Comandos de automação (abrir apps, sites e ferramentas).
- [ ] Interface visual futurista para celular/PC.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python 3
* **Inteligência Artificial:** Google Generative AI (Gemini 1.5 Flash)
* **Hospedagem de Código:** GitHub
